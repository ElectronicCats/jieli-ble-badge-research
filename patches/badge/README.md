# badge-menu patch

Custom **badge-menu firmware** (LVGL touch UI + BLE tools) for the JieLi AC707N/BR35, kept as a
patch on top of the **vanilla** JieLi watch SDK. The SDK itself is **not** stored here — it is the
git submodule at `tools/community-re/jieli-sdks/e_badge_707_sdk_200` (JieLi's private GitLab, pinned
at the vanilla `main` commit). This keeps JieLi's proprietary SDK out of this repo while making the
custom work reproducible.

## Files

- `badge-menu.patch` — the source delta (50 text files, `git diff` format, paths rooted at the SDK
  repo root: `SDK/…`, plus `README.md` and `docs/BUILD.md`). Text sources only.

## Build

```sh
# 1. Get the vanilla SDK (needs JieLi GitLab access; obtained separately, never redistributed)
git submodule update --init tools/community-re/jieli-sdks/e_badge_707_sdk_200
SDK=tools/community-re/jieli-sdks/e_badge_707_sdk_200

# 2. Apply the badge patch onto the vanilla SDK
git -C "$SDK" apply "$PWD/patches/badge/badge-menu.patch"

# 3. Build (needs the pi32v2 toolchain on PATH and a high open-file limit)
export PATH="/opt/jieli/pi32v2/bin:$PATH"
ulimit -n 65536
( cd "$SDK/SDK" && make clean && BADGE_CHIPKEY=9847 make MENU=1 )
# -> SDK/cpu/br35/tools/{app.bin,update.ufw}
```

## Not carried by the text patch (binary deltas — see below)

The patch is text-only. These binary pieces of the delta are **not** in it and must be handled
separately:

- `SDK/cpu/br35/liba/btctrler.a` — a byte-patched vendor lib (GATT-central WinSize). Apply as a
  `git diff --binary` patch, or via a dedicated byte-patch script.
- `SDK/tools/linux/*` — the native Linux post-build tools (`isd_download`, `ufw_maker`, …). Needed
  for the post-build packaging step (`download.sh`). Provide them alongside the SDK.
- Generated artifacts (`config.dat`, `data.bin`, `text.bin`, `download.sh`, …) are regenerated by
  the build and are intentionally **excluded**.

## Regenerating the patch

From the working SDK tree (vanilla + your changes staged):

```sh
git diff --cached -- ':!*.a' ':!*.bin' ':!SDK/tools/linux/**' ':!*.cbp' ':!**/*.bat' \
  ':!**/json.txt' ':!build/fileList.dumy' > patches/badge/badge-menu.patch
```
