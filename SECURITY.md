# Security & Disclosure

## Scope
This repository documents reverse-engineering of a **JieLi AC707N / BR35** BLE e-badge
(the "E87") and related JieLi AC70xx devices: how they handle BLE OTA, firmware
packaging, and on-device key handling.

## Disclosure posture
- This is **independent research**, released for educational and defensive purposes. It
  was **not** coordinated with the device vendor prior to publication.
- No OEM firmware, mobile-application binaries, extracted application/cloud crypto
  keys, or proprietary vendor datasheets are included. The firmware images shipped here
  are self-built.

## Reporting
If you are a manufacturer or maintainer and want to discuss anything here, open a
GitHub issue (or contact Electronic Cats). Please report **security-sensitive** matters
privately rather than in a public issue.

## Using this responsibly
Only exercise these tools against hardware you own or are authorized to test. See
`DISCLAIMER.md`.
